Listening Between the Lines: A year of Spotify Data

This project transforms a year of raw Spotify streaming data into an interactive machine learning-driven analytics application. The platform uses a custom-engineered three-column technical architecture to map hidden behavioural patterns, highlight anomaly thresholds and profile listening habits over time.

Tech Stack: Python (Pandas), Scikit-Learn, Streamlit, Plotly

Role: Data Scientist

Live Demo: Streamlit | Source Code: GitHub

the pipeline

Core Engineering & Machine Learning Architecture

Behavioural Segmentation (K-Means Clustering)

To move beyond surface-level top charts, the pipeline aggregates raw streams into continuous listening sessions (time gaps > 30 mins)

  • Feature Engineering: Sessions are vectorized across 8 multidimensional features: total minutes played, absolute track count, unique artist distribution, skip rate metrics, average duration per track, weekend vs weekday and explicit time of day ratios (evening vs late night).
  • Algorithmic Modeling: Features are isolated and scaled via StandardScaler to ensure zero-mean and unit variance, then fed into the K-Means Clustering algorithm at k=4.
  • Output: Maps music sessions into four distinct behavioural profiles:
    • Deep Dive (focused, uninterrupted album listening)
    • Marathon Mode (high volume, long duration background loops)
    • Browsing Mode (playlist skimming with high skip rate)
    • Evening Unwind (structured, after hours routine listening)
anomaly detection

Structural Outlier Detection (Isolation Forest)

To pinpoint days of irregular user behaviour, such as study listening sessions, the application implemented unsupervised anomaly detection

  • Algorithmic Modeling: A non-parametric Isolation Forest model isolates anomalous data points by randomly partitioning features across the daily aggregated dataset
  • The Output: Computes anomaly scores to separate standard listening behaviour from statistical anomalies, overlaying contextual data tracking on identified peak outliers across historical timeline.
design

Front End & UI/UX Design

  • Macro 3-Column Interface: Built a bespoke dashboard layout optimized for horizontal telemetry. The interface isolates stacked KPI telemetry cards on the far left, centers high-density Plotly data trends in the middle view, and structures tabular breakdowns and clustering distributions on the right panel.
  • Unified Visual Theme: Overrode the default Streamlit canvas using injected CSS to maintain a clean aesthetics. This features custom card containers, transparent chart backgrounds and readable typography.
  • Asynchronous UX: Integrated custom JavaScript scroll-reveal viewport observer using an asynchronous IntersectionObserver iframe component to animate panels into view as the user scrolls.

Movie Recommender System: Hybrid Filtering & Evaluation

Designed and deployed a dual-approach recommendation engine analyzing the MovieLens 1M dataset. The system solves both cold-start and personalization challenges by combining content metadata matching with matrix-factorization-based collaborative filtering.

Tech Stack: Python (Pandas), Scikit-Learn, Streamlit

Role: Data Scientist

Source Code: GitHub

technical execution

Machine Learning Approaches

Content Based Filtering

  • Constructed feature vectors using TF-IDF on genre metadata and calculated cosine similarity matrices to output immediate, title-matched recommendations.

Collaborative Filtering (SVD)

  • Leveraged the Surprise library to train Singular Value Decomposition model on historical user rating data, learning latent factors to predict unobserved user-item preferences.

Interactive UI:

  • Built a responsive Streamlit front-end allowing users to toggle between movie-title similarity search and personalized user-ID recommendation feeds.
model evaluation & metrics

Performance Results

Random Baseline

  • Error (RMSE): 1.05
  • Absolute Error (MAE): 0.84
  • Optimization: N/A

SVD Matrix Factorization

  • Error (RMSE): 0.8729
  • Absolute Error (MAE): 0.6845
  • Optimization: 17% error reduction

Zara Website Redesign

Balancing High-Fashion Aesthetic with Functional E-Commerce Usability

Zara is a leading global fast-fashion brand, yet its desktop e-commerce platform faces persistent criticism for poor navigation, low contrast, and non-standard layouts. This project evaluates key usability breakdowns across Zara’s desktop experience and proposes a redesigned interface that improves task flow, wayfinding and WCAG accessibility while preserving the brand’s signature minimalist aesthetic.

Tools: Figma, Competitive Analysis, Heuristic Evaluation Frameworks

Role: UX Researcher, UX Designer

research & discovery

To map systematic usability issues, the research phase combined quantitative heuristics with qualitative user sentiment:

  • Nielsen Heuristic Evaluation: Evaluated an end-to-end checkout flow for basic apparel item. Identified critical usability breaches across Aesthetic & Minimalist Design, Flexibility & Efficiency of Use and Recognition Rather Than Recall (rated on a 0-4 severity scale).
  • Secondary Market Research: Aggregated qualitative user complaints across Reddit and Medium. Key findings highlighted severe user frustration, often driving site abandonment and lost sales due to unintuitive navigation and low visual contrast.
  • Competitive Benchmarking: Evaluated key competitors (H&M and Uniqlo). Benchmarks revealed that industry leaders consistently utilize structured breadcrumbs, uniform product grids, high text-to-background contrast, and actionable homepage CTAs.

Heuristic Evaluation & Competitive Analysis

exploration & trade off analysis

Before finalizing the interface, multiple conceptual layouts were prototyped and weighed against user goals and brand equity:

key design solutions

Wayfinding and & Breadcrumb Architecture

Introduced persistent breadcrumb trains, inspired by industry standards to allow effortless step backs along the catalog hierarchy

Uniform Product Grid

Replaced Zara's inconsistent pyramid layout with an even grid structure, reducing visual fatigue and streamlining product comparison

Contrast & WCAG Compliance

Increased typography sizing to ensure readability

Call To Action

Added minimalist banner CTA on the landing page to surface seasonal collections immediately upon entry to site
